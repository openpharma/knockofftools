# Simulated dataset for knockofftools

A synthetic dataset generated by the function
[`generate_simdata()`](https://openpharma.github.io/knockofftools/reference/generate_simdata.md).
It contains simulated Gaussian, binary, and survival outcomes along with
covariates.

## Usage

``` r
simdata
```

## Format

A data frame with 2000 rows and 33 variables:

- Yg:

  Continuous outcome

- Yb:

  Binary outcome

  Treatment indicator
